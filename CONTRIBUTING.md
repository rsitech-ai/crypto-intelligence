# Contributing

Every non-merge commit must be signed under Developer Certificate of Origin:

```bash
git commit -s -m "type: focused change"
```

Contributions must preserve exact numeric authority, point-in-time correctness,
bounded resources, local-only operation, explicit data quality and abstention,
no automated execution, and evidence-backed model promotion.

Add or tighten the behavioral test first, run all locally available checks, and
record unavailable platform verification as debt rather than as passing.
Datasets, model weights, address labels, fixtures, and vendor schemas require
source, version, license, redistribution, retention, ownership, and integrity
metadata.
